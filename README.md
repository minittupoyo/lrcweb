# LRC Studio

React・TypeScript・shadcn/ui・Tailwind CSS で作成した、日本語の LRC 歌詞エディターです。歌詞と音声をブラウザー内で編集し、LRCLIB から歌詞を検索できます。

## 起動

Bun 1.4.2 以上が必要です。

```bash
bun install --frozen-lockfile
bun run dev
```

http://localhost:5173 を開いてください。初回は空のプロジェクトから開始し、保存済みの編集内容があれば復元します。

## 使い方

1. 「音声を選択」またはドラッグ＆ドロップで音声を読み込みます。
2. 「テキスト / LRC」で歌詞を入力します。通常のテキストと `[00:12.50]歌詞` を混在できます。LRC / TXT ファイルの読み込み、複数行の貼り付けにも対応します。
3. 音声を再生し、歌い出しで歌詞の行にタイムスタンプを設定します。歌詞一覧では Enter、テキスト入力中では Alt+Enter を使います。
4. 行ごとの − / ＋ ボタンまたは Alt+K / J で微調整します。下部の「調整幅」は 0.01・0.05・0.1・0.25・0.5・1 秒から選べます。初期値は 0.1 秒です。
5. プレビューを確認し、「書き出す」で UTF-8 の `.lrc` を保存します。

「LRCLIB」では曲名・アーティストで検索し、歌詞をプレビューして LRC またはプレーンテキストを取り込めます。取り込みで現在の歌詞と楽曲情報を置き換えます。「元に戻す」で復元可能です。

ヘッダーのリセットアイコンでは、確認後に歌詞・楽曲情報・音声・再生設定・編集履歴を消去します。リセット後の空の状態も保存します。

## ショートカット

Alt の操作は「テキスト / LRC」の入力中にも使え、カーソル行が対象です。通常の Enter は改行です。

| キー | 操作 |
| --- | --- |
| Alt+Enter | 現在時刻をスタンプして次の歌詞行へ |
| Alt+X | カーソル行のタイムスタンプから再生 |
| Alt+Z | 現在時刻をスタンプし、その行に留まる |
| Alt+K / J | タイムスタンプを早める / 遅らせる |
| Space | 再生 / 一時停止（入力欄の外） |
| Enter | 選択行を同期して次へ（入力欄の外） |
| ↑ / ↓ | 歌詞一覧の選択行を移動（入力欄の外） |
| Ctrl / ⌘ + Z | 元に戻す |
| Ctrl / ⌘ + Shift + Z | やり直す |

## 仕様

- 編集内容は localStorage に自動保存します。音声は保存しないため、再読み込み後は再選択してください。
- 選択した音声・編集した歌詞はサーバーに送信しません。LRCLIB 検索時のみ検索語を [LRCLIB API](https://lrclib.net/docs) に送信します。
- LRC 書き出しには同期済みの行だけを時間順に含めます。未同期行は含めず、書き出し後の通知に表示します。
- 曲名・アーティスト・アルバム・オフセットを編集できます。オフセットは ms 単位で、正の値は表示を早めます。スタンプ・再生位置も補正します。
- テキスト編集中の空行・未完成のタイムスタンプはそのまま保存します。メタデータ行は同期対象外です。
- スタンプ操作は行頭のタイムスタンプを一つに置換します。微調整では同じ行の複数タイムスタンプをすべて調整します。0 秒未満にはしません。
- 画面はビューポートの高さに収まり、歌詞一覧・テキスト・楽曲情報は内部スクロールします。同期後の選択行は中央付近に移動します。
- スマートフォンではヘッダーの設定アイコンで楽曲情報・プレビューに切り替えます。
- 音声はブラウザーが対応する形式を利用できます。LRCLIB 検索にはネットワーク接続が必要です。
- 過去に保存された未編集のデモ歌詞は削除し、編集済みの内容は保持します。

## 開発コマンド

| コマンド | 内容 |
| --- | --- |
| `bun run dev` | 開発サーバー（5173 番ポート） |
| `bun run check` | Biome・型チェック・単体テスト |
| `bun run check:fix` | Biome の安全な自動修正 |
| `bun run lint` | lint |
| `bun run format` | コード整形 |
| `bun run format:check` | 整形状態のチェック |
| `bun run typecheck` | アプリ・設定・テストの型チェック |
| `bun run test` | 単体テスト |
| `bun run test:watch` | 単体テストの監視実行 |
| `bun run test:e2e` | Chromium の操作テスト（4173 番ポート） |
| `bun run test:e2e:ui` | Playwright のテスト UI |
| `bun run build` | 型チェック・本番ビルド |
| `bun run preview` | ビルド成果物のプレビュー |

E2E テストの初回実行前に Chromium をインストールしてください。

```bash
bunx playwright install chromium
bun run test:e2e
```

Linux のブラウザー依存ライブラリーが必要な場合は、対応環境で `bunx playwright install --with-deps chromium` を使えます。失敗時のトレース・スクリーンショットは `test-results/`、HTML レポートは `playwright-report/` に保存します。

GitHub Actions の設定は `.github/workflows/ci.yml` にあります。ロックファイルで依存関係を固定し、チェック・ビルド・操作テストを実行します。開発方針とファイル構成は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。
